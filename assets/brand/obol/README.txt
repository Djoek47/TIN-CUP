TIN CUP · a coin for the crossing

Every file is 1024x1024 SVG on a 0 0 100 100 grid. Scale freely.
Coin centre 50,50. Liquid surface sits at y=56 in all marks, so any two
files cross-fade as one object.

  icon-day-gold.svg            3b  amber glass, one hue

  icon-night-gold.svg          3d  edge-lit, gold bloom

NOTES
- iOS: the icons have the squircle baked in. For the current icon system
  you want the glyph alone with no background — use the mark- or rank-
  files and let the OS composite Default / Dark / Clear / Tinted.
- Highlights are tuned for large sizes. Below 44px thicken strokes by
  roughly 2x (see the size tests in the design file).
- Colours: amber #FFB43D (given), lime #C4F000 (received), bone #EDE6D6
  (replaces lime in the Lord world), ink #F4F3F0, canvas #08090B.
- Blur filters are used for glow. Flatten them before handing to a
  fabricator or an embroiderer.
- These are design files, not trademark-cleared artwork. Clear the name
  OBOL before you ship it.
