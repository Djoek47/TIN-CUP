HOW TO RUN IN CURSOR (5 MINUTES):

1. Clone & setup:
   git clone https://github.com/Djoek47/TIN-CUP.git
   cd TIN-CUP && git checkout tin-cup
   npm install

2. Environment:
   cp .env.example .env.local

3. Build & run:
   npx expo prebuild --clean
   npm run dev

4. Open http://localhost:3000 and test
